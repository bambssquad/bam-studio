# Minimalist design research

Reviewed 21 September 2026. This is a design interpretation, not a copy of another studio's website.

## Sources and application

- John Pawson, Architecture: https://www.johnpawson.com/architecture
  Observed the live page and screenshot: substantial negative space, restrained navigation, simple project titles, location/year metadata, and photography. Apply concise metadata and generous spacing while retaining Bambe's existing navigation.
- Norm Architects: https://normcph.com/
  Reviewed the project presentation and content: architecture is organized around project photography, category, and year. Apply a larger lead project with quieter supporting entries.
- Nielsen Norman Group, Flat-Design Best Practices: https://www.nngroup.com/articles/flat-design-best-practices/
  Minimal styling must still communicate what is interactive. Keep underlines on links, visible selected filters, keyboard focus, and 44px filter targets.

## Design decisions

- Preserve project data, navigation labels, section anchors, wordmark, and metadata.
- Replace the green section blocks, pill filters, photo overlay, and decorative numbering with a neutral gallery presentation.
- Palette: canvas #fafaf8, ink #242622, secondary #656860, dividers #dcded7, image fallback #e8e9e3.
- Manrope for display text; DM Sans for UI and body. One large leading project is the signature composition.
- Put the hero caption outside the photograph for stable contrast. Let natural material colors come from photography.
- Keep the two-column supporting gallery on desktop and a single column on mobile. Honor system dark mode and reduced motion.
- No animation library, routing change, backend, or invented contact details.

## Content boundary

Project data and photographs remain demonstration content. Replace them with actual studio work before publication. External fonts and images need internet access.
